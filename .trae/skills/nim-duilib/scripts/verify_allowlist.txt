# nim_duilib 文档校验豁免名单
#
# 用途：verify_docs.py 会检查文档里引用的控件宏（DUI_CTR_*）、事件名（kEvent*）、
#       类名（ui::Xxx）、字体 ID、语义色名是否真实存在于源码。下列名字属于
#       **示例占位符 / 通配写法 / 尚未落地的规划项**，是文档有意引用的，不算漂移。
#
# 语法：
#   <glob> :: <名字1> <名字2> ...
#       glob 相对于仓库根（也可用文件名匹配），支持 * 通配；多个 glob 用空格分隔。
#       glob 与名字列表之间用 "::" 分隔。
#   :: <名字1> <名字2> ...
#       不限定文件，对所有被扫描文档生效。
#   # 开头为注释，空行忽略。
#
# 维护约定：优先写带 glob 的形式，避免豁免范围过大让检查失去敏感度。
#         本文件只登记"故意引用"，不得用于掩盖真实漂移。
