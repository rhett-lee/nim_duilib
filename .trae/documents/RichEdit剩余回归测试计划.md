# RichEdit 示例：剩余回归测试计划

## Context（为什么还需要这份计划）

examples/RichEdit 已完成第二轮 Review，并修复了 5 个问题（F1 分组标题点击坐标、F2 拖放失败提示文本 ID、F3 富文本示例格式独立设置、F4 字体对话框"应用到全文"、F5 SDL 下不写 rich_text 设置），另新增了状态栏行列越界保护。

目前处于"修复后全面系统功能测试"阶段：SDL 平台已回归大部分功能，仍有若干项未验证；Windows 平台尚未构建与测试。本计划描述**剩余验证动作**，不预设代码改动——只有当测试暴露缺陷时，才按"发现即修、改完即回归"的方式处理。

## 已完成（本轮上下文已确认）

- SDL 主窗口运行中（PID 11648 / HWND 3016090，客户区 2038x1411，桌面 DPI 175%）。
- F1 回归通过：左侧分组"密码相关功能/基本功能/常用功能"在**顶部**与**滚动后**两种状态下点击标题均能正确折叠/展开（滚动后点击命中正确）。
- "设置字体"按钮在 SDL 下为禁用态，点击无响应、无异常。
- 选中文本后点击 B：复选框选中、文本变粗体，生效正确。
- 字体名称下拉框可正常弹出（弹出为独立 HWND，371x620），列表内容为系统字体列表。
- 方法学要点：`PostMessage(WM_MOUSEWHEEL)` 无法驱动 SDL 滚动，必须用 `SetCursorPos` + `mouse_event(MOUSEEVENTF_WHEEL)`；Combo 的下拉箭头位于控件最右侧（约组合框右边缘 5px 内），点击文本区只会聚焦编辑框。

## 剩余工作

### 1) 完成 SDL 平台剩余测试

| 项 | 操作要点 |
|---|---|
| 字体名称选择 | 下拉已打开（HWND 2754814），点击条目"Arial"（弹出窗口客户坐标约 y=50~60，项高约 50），确认字体名回填且正文生效 |
| 字号选择 | 点击字号组合框箭头（约 x=1310~1330, y=384），选择"小四/12"等，确认字号变化与状态回填 |
| 字体颜色 / 更多颜色 | 点击颜色 ComboButton（约 x=1690~1710, y=384）选色；再点"更多颜色"打开 ColorPicker，确认确认/取消两条分支 |
| B/I/U/S 四态 | 逐项切换并确认正文样式与复选框状态同步 |
| A+/A- | 确认字号递增/递减 |
| Ctrl+滚轮 / Ctrl+0 缩放 | 在编辑区聚焦后按住 Ctrl 滚轮，确认状态栏缩放百分比变化；Ctrl+0 恢复 100% |
| 文件：新建/打开/保存/另存为 | 新建清空并重置标题；打开 .rtf/.txt；保存与另存为落盘且标题去星号 |
| 拖放 | 拖入 .txt/.rtf 到窗口，确认加载；拖入不支持类型确认失败提示文案（F2） |
| 状态栏提示 | 触发一次提示，确认 3 秒后自动消失 |

### 2) 构建 Windows Debug x64

```
msbuild examples\RichEdit\RichEdit.vcxproj /p:Configuration=Debug /p:Platform=x64 /p:SolutionDir=e:\develop\nim_duilib\build\ /m:1
```

仅 Debug x64，不构建 Release。

### 3) Windows 平台系统测试

在 SDL 测试项基础上，追加 Windows 专有项：

- 超链接点击、拖放 .rtf
- 状态栏行列显示与越界保护

## 验证方式

- 每一项以截图/状态栏文本为证据；发现异常先定位是示例代码问题还是框架行为，再决定是否修改。
- 任何代码改动后：重新构建对应平台（Debug x64）→ 复跑该项 → 再跑一遍相邻回归项，确认无副作用。
- 最终判定标准：SDL 与 Windows 两平台在上述所有测试项上均无异常、无崩溃、无错误提示。
