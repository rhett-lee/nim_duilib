# RichEdit 示例程序冒烟测试清单

用于 RichEdit 示例（`examples/RichEdit`）每次改动后的手工回归，避免重复踩坑。

- 测试程序：`bin/RichEdit_d.exe`（Debug x64 构建产物）
- 参考界面资源：`bin/resources/themes/default/rich_edit/rich_edit.xml`
- 设置文件：`bin/user/RichEdit_settings.ini`（删除后恢复默认设置）
- 测试前建议：先删除设置文件，确认默认状态下的表现

## 一、启动与布局

- [ ] 双击启动，窗口正常显示，无崩溃、无黑块、无闪烁
- [ ] 左侧演示面板与右侧编辑区布局正常，窗口拉伸时不错位
- [ ] 编辑区出现示例文档（含标题、快捷键说明、行距示例），光标在文首
- [ ] 状态栏各项（路径、行列、字符数、缩放、模式、编码）均有内容

## 二、文件操作

- [ ] 新建（Ctrl+N）：清空内容，提示"未命名"，无未保存确认打扰
- [ ] 新建前有未保存修改时弹确认框：取消 / 否 / 是（是=先保存）
- [ ] 打开（Ctrl+O）：可选文件类型包含 TXT，富文本模式下额外包含 RTF
- [ ] 打开 UTF-8 / UTF-16 / ANSI 文本均不乱码，状态栏"编码"显示正确
- [ ] 打开空文件：内容被清空，不残留上一次的文本
- [ ] 保存（Ctrl+S）：示例文档/未命名文档自动转为另存为，不会覆盖示例资源
- [ ] 另存为（Ctrl+Shift+S）：默认扩展名随模式变化（富文本 rtf / 纯文本 txt）
- [ ] 保存后标题栏"保存"按钮的 `*` 消失，状态栏修改标记消失
- [ ] 拖入 `.txt` / `.rtf` 文件可直接打开；拖入其他类型无反应
- [ ] 打开/保存失败时有错误提示框（不是静默失败）

## 三、文本编辑

- [ ] 复制、剪切、粘贴、删除、全选、取消选择、撤销、重做均生效
- [ ] 无选区时复制/剪切/删除按钮置灰；有选区时恢复可用
- [ ] 撤销/重做/粘贴按钮的可用状态随内容变化正确刷新
- [ ] 大文件全选（Ctrl+A）时界面不卡顿
- [ ] 右键菜单粘贴、输入法输入后，保存按钮的 `*` 能正确出现

## 四、字体与字符格式

- [ ] 字体名称下拉可展开，条目显示完整，长字体名有提示
- [ ] 切换字体名称立即作用于当前选区（或全文）
- [ ] 字号下拉切换生效；"增大字体/减小字体"按钮逐级变化
- [ ] 粗体、斜体、下划线、删除线可独立开关，选中状态与光标处格式一致
- [ ] 颜色下拉选色生效，色块与文字颜色一致
- [ ] 颜色选择器"取消"后，文字颜色与色块都恢复为原颜色
- [ ] "更多颜色"打开拾色器，确认/取消行为正确
- [ ] 勾选"应用到全文"后改字体/字号/颜色，全文生效且原选区保持不变
- [ ] "设置字体"按钮打开系统字体对话框，确定后字体与颜色同步更新

## 五、行距

- [ ] 富文本模式下行距选项可用，切换 1.0/1.15/1.5/2.0/2.5/3.0 立即生效
- [ ] 纯文本模式下行距选项与"应用到全文"置灰不可点

## 六、缩放

- [ ] 缩放下拉选择 50%~400% 生效，状态栏与缩放标签同步
- [ ] 缩放编辑框直接输入 `150` 或 `150%` 回车后生效，非法输入回退为当前比例
- [ ] `Ctrl+0` 复位为 100%
- [ ] `Ctrl+滚轮` 可缩放，标签、下拉、状态栏同步刷新
- [ ] "复位"按钮回到 100%
- [ ] 缩放项 tooltip 中写明了快捷键

## 七、自动换行与文本模式

- [ ] 自动换行勾选后长行折行、关闭后出现横向滚动条
- [ ] 勾选/取消"富文本"切换生效，状态栏模式显示同步
- [ ] 富文本切到纯文本时弹出确认框；取消则复选框保持勾选
- [ ] 纯文本切到富文本正常，不遗漏撤销栈以外的异常

## 八、查找与替换

- [ ] 查找（Ctrl+F）打开窗口，Esc 关闭，输入框自动聚焦
- [ ] 查找窗口预填编辑区当前选中的文字（无选中时预填上次查找内容）
- [ ] 查找下一个：命中项被选中并滚动到可见区域，窗口不遮挡命中内容
- [ ] 向上/向下搜索方向生效
- [ ] 区分大小写、全字匹配开关生效
- [ ] 查找结果计数显示"第 N 处，共 M 处"或"共 M 处"
- [ ] 未找到时显示"未找到"，状态栏提示 3 秒后自动消失（不是常驻）
- [ ] 主窗口 `F3` 查找下一个；无查找内容时 F3 打开查找窗口
- [ ] 替换（Ctrl+H）：单次替换后自动查找下一个
- [ ] 替换为空字符串可用（即删除命中内容）
- [ ] 全部替换：状态栏提示"已替换 N 处"，内容与修改标记正确
- [ ] 查找/替换窗口的选项在关闭后重新打开仍然保留
- [ ] 替换窗口 Enter 触发替换，Esc 关闭

## 九、状态栏

- [ ] 文件路径显示正确，未命名时显示"未命名"，有修改时追加 `*`
- [ ] 行列号随光标移动正确变化
- [ ] 字符数显示正确，有选区时额外显示"选中 N"
- [ ] 缩放比例、模式（富文本/纯文本 · 换行开/关）、编码显示正确
- [ ] 提示信息（未找到/已替换 N 处）3 秒后自动清除
- [ ] 执行文件类操作（新建/打开/保存）后提示信息清除

## 十、左侧演示面板

- [ ] 各组（密码、基础、更多功能、滚动条）点击标题可折叠/展开，标题箭头随之变化
- [ ] 折叠后分组仍保留标题高度，不塌陷为 0
- [ ] 密码框、只读框、超链接演示正常；点击超链接由系统浏览器打开
- [ ] 两个"单行编辑"示例能看出差异（默认样式 vs `text_padding`）
- [ ] 滚动条、多行文本框等其他演示控件正常

## 十一、设置持久化

- [ ] 调整左侧面板宽度后关闭程序，重开后宽度恢复
- [ ] 修改缩放比例、自动换行、富文本模式、字体名称后重开，设置恢复
- [ ] 删除 `bin/user/RichEdit_settings.ini` 后重开，恢复全部默认值
- [ ] 旧版本设置文件（无 `settings_version` 或小于 2）升级后不出现异常布局

## 十二、窗口与收尾

- [ ] 有未保存修改时关闭窗口：取消不退出、否直接退出、是保存后退出
- [ ] 存在未关闭的查找/替换窗口时关闭主窗口，子窗口一起关闭，无崩溃
- [ ] 切换界面语言后：按钮文字、分组标题箭头、示例文档、状态栏均刷新正确
- [ ] 在不同 DPI 显示器间拖动窗口，字号列表与颜色块不失效
- [ ] 反复打开/关闭程序 5 次，无崩溃、无残留进程
